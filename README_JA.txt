Live Japanese Captions Edge / Chrome v0.5.0（評価版）

[インストール]
1. ZIPを解凍。Edgeで edge://extensions を開き、開発者モードをONにする。
2. 展開して読み込むから extension フォルダーを選択。
3. 拡張機能のオプション画面で字幕モードを選び、設定を保存。
4. 無料ローカルモードは従来通りWhisperと翻訳モデルを準備。
5. AssemblyAIモードは英語専用。APIキーを端末内に保存し、利用上限を設定。ローカル英日翻訳モデルを準備。
6. PCのYouTube Live動画タブで拡張アイコンを押して開始、再度押して停止。

[重要]
AssemblyAIモードは再生音声を外部送信し、API従量課金が発生します。
APIキーはこのブラウザのローカル拡張機能ストレージにのみ保存します。ブラウザプロファイルにアクセスできる第三者からの秘匿は保証しません。共有PCではキーを削除してください。
初期セッション上限は10分です。AssemblyAI側の利用上限も設定してください。
無料モードの音声認識と翻訳はPC内処理です。両モードとも初回モデル取得には通信が必要です。
G83/HVやYouTube Live実配信での有料モード連続動作・遅延は未確認です。
YouTubeのスマホアプリにはこのブラウザ拡張は組み込めません。
